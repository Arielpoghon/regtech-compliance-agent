# DoraHacks Submission — BLI Legal Tech Hackathon 2

## Build title
RegTech AI Compliance Agent

## Track
LegalTech & RegTech

## Short description (1-2 lines)
AI compliance agent for smart contracts and RWA tokens: paste a contract,
pick a jurisdiction (US/EU/SG/UAE), get a risk score, sanctions hits,
KYC/AML posture, and a legal-document attestation report in seconds.

## Long description
Smart contracts and RWA tokens ship without a compliance review: legal
teams can't read Solidity, auditors don't check sanctions/KYC. Projects
launch with unilateral minting, upgradeable proxies with no timelock, and
sanctioned addresses hardcoded — discovered only after the fact.

RegTech AI Compliance Agent closes that gap. Given a contract address or
source code plus a jurisdiction, it runs a 14-pattern heuristic analyzer
(owner/admin, pause, blacklist/whitelist, mint/burn, upgrade, oracle,
reentrancy, KYC hooks, transfer restrictions, multisig, timelock, emergency
rescue) and screens extracted addresses against an OFAC sanctions slice.
It then produces a jurisdiction-aware compliance report covering:
(1) Summary with risk score, (2) Sanctions screening, (3) KYC/AML posture,
(4) Legal document attestations (disclosure/stablecoin framework), and
(5) Recommendations. Jurisdictions supported: US (SEC/FinCEN, GENIUS Act),
EU (MiCA), Singapore (MAS), UAE (VARA/SCA).

The report is generated by an LLM when an API key is present, with a
deterministic fallback so the demo works fully offline. Backend is
stdlib-only Python (no heavy deps); frontend is a single-page app with no
build step.

## Tech stack
Python 3.14 (stdlib), HTML/JS + Tailwind (CDN), OpenAI-compatible LLM
(optional).
